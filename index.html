How to play

Choose a vessel, then a matching top color or an empty vessel. A pour moves the full matching run that fits. Fill each color’s vessel to settle it.

Free pairs may pour together. Undo restores the previous pour. Hint points toward a solution without changing your board. Restart begins this commission again.

Keys 1–6 select vessels; H, U and R use the tools. Color names are available on each vessel.

Haptics depend on device support.
