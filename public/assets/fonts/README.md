# Cinzel

Self-hosted original Google Fonts Cinzel font files, weights 500, 600 and 700. Downloaded 2026-10-05 from the font URLs returned by:

https://fonts.googleapis.com/css2?family=Cinzel:wght@500;600;700&display=swap

The accompanying SIL Open Font License was obtained from the Google Fonts repository's `ofl/cinzel/OFL.txt`. Copyright belongs to the Cinzel Project Authors; font files were not modified. No external font request is made at runtime.
